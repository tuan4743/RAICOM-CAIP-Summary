# 14 类 → 4 类映射规则

按天气语义归并。验收要求 4 类：cloudy / rainy / snowy / sunny。

## 映射表

| 14类 | → 4类 | 语义依据 |
|------|-------|----------|
| cloudy | cloudy | 多云/阴天，直接对应 |
| fogsmog(雾霾) | cloudy | 雾霾遮蔽天空，偏阴/多云 |
| dew(露水) | cloudy | 露水形成于夜间晴朗或阴湿，偏阴湿；归 cloudy |
| rain | rainy | 直接对应 |
| hail(冰雹) | rainy | 冰雹属强对流降水，归 rainy |
| lightning(闪电) | rainy | 闪电伴随雷雨，归 rainy |
| snow | snowy | 直接对应 |
| frost(霜) | snowy | 霜冻属冰雪现象，归 snowy |
| glaze(雨凇) | snowy | 冰冻覆盖，归 snowy |
| rime(雾凇) | snowy | 雾凇冰晶，归 snowy |
| sunny | sunny | 直接对应 |
| rainbow(彩虹) | sunny | 彩虹常现于雨后初晴，归 sunny |
| sandstorm(沙暴) | sunny | 沙暴多发于晴朗干燥大风，归 sunny |
| tornado(龙卷) | cloudy | 龙卷伴随强对流云墙，归 cloudy（无更好归属） |

## 归并后 4 类来源
- **cloudy** ← cloudy, fogsmog, dew, tornado
- **rainy** ← rain, hail, lightning
- **snowy** ← snow, frost, glaze, rime
- **sunny** ← sunny, rainbow, sandstorm

## 注意
- tornado/dew/rainbow 归属有主观性，方案B对比时若精度不及预期可调整。
- 推理脚本 `predict.py` 将内置此映射表，14类模型 logits 先 argmax 得14类，再查表转4类。
- 也可用"4类合并 logits"法：把同属一组的14类logits相加再argmax，比硬argmax更稳。两法都实现，对比择优。
