# 训练方案与脚本改造

## 一、改造 main.py 的要点

在现有冻结版基础上增加（保留全量预加载以加速 V100 训练）：

### 1. 渐进式解冻（核心）
- Phase 1（前 N1 epochs）：冻结 backbone，只训 head，lr=1e-3
- Phase 2（N1 ~ N2 epochs）：解冻后段 blocks（stage5/6），lr=2e-4
- Phase 3（N2 ~ 末）：全网络解冻，lr=5e-5（差分学习率：backbone 更小，head 更大）
- 用 `--unfreeze-epoch` 已有参数 + 新增 `--full-unfreeze-epoch`

### 2. AMP 混合精度
- `torch.cuda.amp.GradScaler` + `autocast`，V100 上加速 ~1.5×，省显存可上更大 batch

### 3. 不均衡处理（4 类方案）
- `WeightedRandomSampler`：按 `1/freq` 加权采样，让 rainy/snowy 被多抽
- 备选：Focal Loss（gamma=2）。两者择一或叠加

### 4. 差分学习率
- backbone 参数 lr × 0.1，head/classifier lr × 1.0

### 5. 解冻后降低正则
- 解冻后 Mixup alpha 降到 0.2，避免欠拟合
- 保留 label_smoothing=0.1、grad_clip=1.0

## 五、当前主攻方案（v6 split, 验收同分布）

### 关键认知修正（中段调整）
1. **验收测试集 ≠ 任何训练test集**：组委会独立持有，与 `dataset/`（4999张224原版）同分布，与 `dataset_aug3`（HD高清）不同分布。
2. **验收指标 = F1 macro**（非 accuracy），少数类 rainy 权重高。
3. **验收类别顺序 = `['sunny','cloudy','rainy','snowy']`**，与 sorted() 字母序不同 → 必须用 `--classes-override` 对齐。
4. aug3 在自身test 95% 但跨分布测 `dataset/` 仅 F1 0.51 → **aug3 不可提交**，已转回 dataset 分布。

### v6 split 训练设置
- 数据：`dataset_split/`（从 dataset/ 85/15 划分，train 4252 / test 747，seed42，硬链接）
- 输入：224原图 上采样到 384（b2 设计尺寸）
- `--classes-override sunny,cloudy,rainy,snowy` 使 checkpoint 输出维度直接对齐验收 class_to_idx
- 在线增强：RandomResizedCrop(384, scale 0.5-1.0) + RandAugment(9) + RandomErasing(p=0.25)
- 渐进式解冻(epoch4) + EMA(0.9995) + TTA(原图+水平翻转) + Mixup/CutMix + Cosine+Warmup

### 第一版（Focal）→ 第二版（CE）改造
- v6 split + Focal：F1 macro **0.8422**，瓶颈 rainy precision 0.6526（过度判 rainy）
- 根因：WeightedRandomSampler + Focal(gamma=2) 对少数类 rainy(380张) 过度补偿
- 改造：**去 Focal 改 CE**（`--focal` 去掉，label_smoothing 0.1 保留），sampler 保留温和补偿
- 评测：`models/eval_f1.py` 自适应 checkpoint 类别顺序，重排到验收顺序算 F1 macro

### 验收推理约束（必须自检）
- 2核8G **CPU** 机器，**70 分钟**内完成全部推理
- CPU pinned：`taskset -c 0,1` + `OMP_NUM_THREADS=2 MKL_NUM_THREADS=2`
- 提交物：训练权重 best.pth + predict.py 推理脚本
