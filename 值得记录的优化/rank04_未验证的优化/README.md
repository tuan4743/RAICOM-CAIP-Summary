## 混合模型(错误独立 ensemble)

状态:未落地.我实际做的 ensemble 全是失败的同 seed/同家族 ensemble,事后复盘才想到可以用"b2+DINOv2 错误互补".
- 根因:同配置多 seed / 同家族 B+L,错误相关,logit 平均无增益.  
- 正确做法:选错误独立的异构模型(如 CLIP 视觉端攻 sunny/cloudy 全局布局,补 DINOv2 的纹理短板),且按类加权(rainy/snowy 听 DINOv2,sunny/cloudy听第二模型).  
- 预期收:：+0.005~0.01，且救不了本质性边界.  
标注:ensemble 有效性的判据是错误独立性，不是模型数量.  

## 5折调参

状态:部分落地.5折 CV 数据集和训练都做了,但我没真正用它"调参"——只用了它做 OOB 评估和选 fold3."用 5折 OOB 指导调参决策",这一步根本没做(G.9/G.10 的消融还是用静态 741 test 比的).
值得记的是"该用而没用"的教训:  
- ±0.001 量级的消融实验(G.9 四个、G.10 四个)全用泄露的静态 test 比,结论噪声内,根本不值得消耗决策注意力.
- 正确做法:这类小差异实验应该用 5折 OOB 的均值±方差判断是否超越 seed 噪声,超了才信.
标注:小量级消融必须用 OOB 均值±方差,静态 test 上的 ±0.001 全是噪声. 8 个消融实验的结论"无一超基线"其实可能就是噪声,不该据此锁死"局部最优"
