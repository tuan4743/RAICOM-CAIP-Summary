# 置信度分档审计脚本
这是最有复现价值的脚本.  
## 它做了什么?  
- 一次前向拿完整 softmax 分布，按置信度分档(high≥0.9 / mid 0.5~0.9 / low<0.5)  
- 输出每图四类概率 + 判错图复制到 hard_examples/  
- 统计错误模式矩阵(true→pred 计数)  
## 这次用对的地方
- 定位瓶颈类:G.1 发现 b2 瓶颈是 rainy/snowy,G.15 发现 DINOv2 瓶颈转移到 sunny↔cloudy.没有审计就会在错误的类上死磕.
- 量化标签噪声:G.16 把 high 档判错图给人复核,识别出 6 张噪声删除,基线上调 +0.0046.这是审计→清洗→提分的完整闭环,可复用.
## 没有用对的地方和潜在价值
- high 档判错 = 标签规则不一致信号,我只用来删噪声,没用来系统重标规则(规则性边界处理).
- 它本该接一层"近邻分析":审计找出判错图后,下一步该查这些图的 train 近邻是否同类,以判断边界类型.我没做这步,导致 av3 盲补.这是审计该有却没有的第二阶段.
